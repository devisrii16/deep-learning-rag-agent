# Long Short-Term Memory Networks

LSTM stands for Long Short-Term Memory. It is a type of recurrent neural network designed to learn long-term dependencies in sequential data.

## LSTM Gates

An LSTM uses three main gates: the forget gate, the input gate, and the output gate.

The forget gate decides what information to remove from the cell state.

The input gate controls what new information is stored.

The output gate determines what information is passed to the next hidden state.

## Applications

LSTMs are used in time-series forecasting, language modeling, and sequence prediction.
